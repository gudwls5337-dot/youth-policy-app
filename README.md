# 청년정책 상황판

전국 지자체의 **청년정책 2,691건**과 **청년 조례 235곳**을 우리 시 기준으로 한 화면에 놓습니다.
목록을 모아 보여주는 곳은 이미 있습니다. 없는 것은 **변화** — 올해 생긴 것, 조용히 사라진 것입니다.

**→ https://gudwls5337-dot.github.io/youth-policy-app/**

홈 화면에 추가하면 앱처럼 열리고, 오프라인에서도 동작합니다.

---

## 무엇이 다른가

| | 보여주는 것 | 답하는 질문 |
|---|---|---|
| 온통청년 | 정책 목록 | "지금 뭘 신청하지?" |
| 법제처 | 조례 원문 (한 번에 한 건) | "이 조례 내용이 뭐지?" |
| SGIS 청년통계지도 | 통계 | "청년이 어떤 상태인가?" |
| **이 앱** | **조문·정책을 한 축에** | **"우리 시는 어떻게 다른가"** |

법제처는 조례를 이미 전부 갖고 있습니다. 다만 **한 번에 한 건씩만** 볼 수 있습니다.
여기서 만드는 것은 새 데이터가 아니라 **새 비교축**입니다.

## 실측이 말하는 것

「청년기본법」은 19~34세인데, **34세를 그대로 쓰는 지자체는 235곳 중 3곳뿐**입니다.

```
상한  34세    3곳   ← 법정 기준
      39세  139곳   ← 절반 이상
      44세    1곳
      45세   49곳
      49세   43곳
하한  19세 133곳 · 18세 93곳 · 15세 4곳
```

## 데이터

| 파일 | 내용 |
|---|---|
| `docs/data/board.json` | 235개 지자체 조례 — 연령 정의·근거 조문·담당부서·전화 |
| `docs/data/definitions.json` | 조례 본문 추출 원본 (대조용 인용문 포함) |
| `docs/data/policies-by-org.json` | 정책 2,691건 + 지자체별 귀속 인덱스 |
| `data/` | API 원응답 스냅샷 (append-only) |

**출처** 법제처 국가법령정보센터 Open API · 한국고용정보원 온통청년 청년정책 API
**라이선스** CC BY — 출처만 밝히면 자유롭게 쓰십시오

## 쓰는 법

```bash
npm install

cp .env.example .env          # 온통청년 인증키 입력
                              # https://www.data.go.kr/data/15143273/openapi.do

npm run collect:ordinances    # 법제처 조례 전수 (키 불필요)
npm run collect:definitions   # 조례 본문에서 연령·담당부서 추출
npm run collect:policies      # 온통청년 정책 전수

npm run build                 # docs/index.html 생성
npm run check                 # 검증 + 화면 동작 테스트
```

정기 갱신은 `npm run refresh` 하나면 됩니다 — 수집·빌드·검증·스모크를 순서대로 돌리고
**어느 단계든 실패하면 배포하지 않습니다.**

## 정확성

정확성이 이 프로젝트의 유일한 자산이라 검증을 3계층으로 나눴습니다.

| 계층 | 잡는 오류 | 명령 |
|---|---|---|
| 불변식 51항목 | 자기모순·형식 위반·필드 유실 | `npm run validate` |
| 표본 재수집 | 파싱 버그·상류 변경 | `npm run validate:deep` |
| 감사 에이전트 | 구조적 오독·의미 오판 | `npm run audit:prepare` |

이 체계가 실제로 잡은 것과 설계 원칙은 [VERIFY.md](VERIFY.md)에 있습니다.
가장 큰 발견은 **연령이 「정의」 조가 아니라 「적용대상」 조에 있는 조례 패턴**을
파서가 통째로 놓치고 있던 것이었습니다 (연령 추출 230/235 → 235/235).

## 알려진 한계

- **미분류 정책 170건** — 주관기관에 지역 단서가 없습니다. 임의 배정하지 않고 그대로 뒀습니다.
- **전화 없음 8곳** — 조례 메타데이터에 번호가 없습니다.
- **제주 서귀포시** — 행정시라 자체 조례가 없습니다.
- **기간 정보 없는 정책 469건** — 원본에 없는 것을 추정하지 않습니다. 담당부서 전화가 그래서 붙어 있습니다.
- **이 데이터는 약속이지 이행이 아닙니다.** 조례가 넓다고 예산이 있는 것은 아닙니다.
